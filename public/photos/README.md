# Photos — manual IG export (do NOT scrape instagram.com/shastriyakid)

instagram.com/shastriyakid is login-blocked, so automated scraping is intentionally
not attempted.

Workflow:
1. User exports photos from Instagram manually.
2. Drop the exported image files into this folder (`public/photos/`).
3. Tell the agent the filenames — the agent will then read each photo via the
   read tool to analyze its content (subject, setting, mood, colours) and wire
   the approved images into the site placeholders.

Keep originals here; do not commit huge RAW files — prefer web-sized JPG/WebP.
